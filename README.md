# qianyilun/tap

Homebrew formulae by [qianyilun](https://github.com/qianyilun).

```bash
brew install qianyilun/tap/<formula>
```

| Formula | What it is |
|---|---|
| [glasstty](https://github.com/qianyilun/glasstty) | Liquid Glass look for the Ghostty terminal on macOS 26 |

After `brew install qianyilun/tap/glasstty`, run `glasstty enable` (add `--tmux` for the tab bar) and reload Ghostty with Cmd+Shift+,.
